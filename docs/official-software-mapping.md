# Official Track Software Mapping

The challenge PDF names the following resources. TABLEMIND uses the smallest useful subset first.

- MuJoCo — primary simulator.
- Hugging Face LeRobot — training/fine-tuning and dataset tooling.
- SmolVLA — primary VLA candidate.
- Pi0.5 / ACT — alternatives/baselines.
- OpenVINO Toolkit — optimization/conversion/inference.
- OpenVINO Physical AI — robotics policy deployment runtime.
- Intel Physical AI Studio — optional development/integration.
- Open Edge Platform — optional edge foundation.
- Edge AI Suites – Robotics — optional reusable robotics components.
- Intel Geti — optional computer-vision tooling.
